От выгрузки к разговору о релизе

Три результата, ради которых стоит открыть Roadmap.

  1. Соберите план из Jira

    Импортируйте CSV и получите иерархию эпиков, историй и задач со сроками на Ганте. Доска помогает разбирать работу по статусам.

    Родители берутся из выгрузки, не угадываются. Задачи без истории остаются отдельно. Типы и направления связей сохраняются.

  2. Поймите, что мешает сроку

    Разберите зависимости, загрузку команды и пропуски в данных. Сравните вариант «Что если», не меняя основной план.

    Прогноз зависит от оценок, связей и доступности команды. Это расчет, а не обещание даты.

  3. Подготовьте материал для встречи

    Выберите нужную часть плана, проверьте предпросмотр и подготовьте статус или презентацию. Не нужно показывать весь рабочий проект.

    Для передачи выбирайте состав и формат отдельно: отчет для просмотра не заменяет рабочий файл.

В v17.1 три основных раздела: «План», «Сроки и риски», «Для встречи». Сохранение рабочего HTML собрано в одном окне; дополнительные инструменты подключаются по необходимости.

Как начать

Демо нужно для знакомства. Для своего плана используйте рабочую версию приложения.

1. Попробуйте демо

Откройте карточки и разные виды плана на вымышленных задачах. Демо не записывает изменения в рабочий файл.

2. Запросите рабочую версию

Напишите автору через форму в начале страницы. Уточните цену, состав поставки, порядок обновления и поддержки до решения о покупке.

3. Сохраните свой план

Создайте план вручную или импортируйте Jira CSV. После правок сохраните рабочий HTML. Если браузер скачал новую копию, переносите именно ее из папки загрузок. Отдельный JSON для переноса не нужен.

Рабочий файл, не облачный сервис

Подходит для личной работы владельца продукта и подготовки материалов для команды.

Что важно до начала работы

Рабочая версия объединяет приложение, план, архив задач и точки возврата в одном HTML. Файл может работать офлайн. Одновременного редактирования и автоматической синхронизации между компьютерами нет: передавайте последнюю сохраненную копию.

В публичном демо только вымышленные задачи, без реальных планов, токенов Jira и финансовых данных команды. Сайт и видео загружаются по сети. Обмен с Jira требует вашей настройки; автоматический обмен работает, только если вы его включили.

Личный HTML с PIN шифруется после скачивания защищенной копии. Четырехзначный PIN можно подобрать. Обычный HTML и отдельные выгрузки не защищены. Не публикуйте личный HTML, даже с PIN.

Перед очисткой проекта сохраните рабочий HTML с точками возврата. Обычный экспорт JSON не копирует историю браузера. Отчет или копия для просмотра не заменяют эту резервную копию.
