# Roadmap v16.1.0

Дата версии: **19.09.2026**. Самостоятельный выпуск после v16.0.1:
интерфейс, объяснимый прогноз, общие правила статусов служебных инструментов
и отдельный модуль итогового ответа «Успеваем?».

Результаты проверки точного состава файлов приведены в `QUALITY_REPORT.md`
и `validation.json`. Размещение в GitHub проверяется отдельно после загрузки;
создание локального комплекта само по себе не обновляет сайт.

## Интерфейс и навигация

- Студия выбрана для первого запуска; явно сохраненная тема не меняется.
  Зеленый логотип остается одинаковым во всех темах.
- Стартовая помощь собрана в один ряд. На телефоне обе кнопки стоят рядом;
  кнопки шапки не занимают область заголовка и пояснения.
- Переключатель Простой/Продвинутый удален. Все возможности доступны без него.
  В «Настройки → Функции» отдельно управляются 13 групп полей карточки
  и четыре элемента шапки. Скрытие не удаляет значения и не меняет расчеты.
  Отдельные настройки функциональных модулей сохраняют свое назначение.
- «Материалы» открываются прямо из шапки; «Выгрузить план в XLSX» находится
  в «Данных». Клавиши, загрузка Jira, сохранение и отправка объединены
  в нижнем блоке справки. Примеры JQL раскрываются отдельно.
- Типы работ различаются подписью и общей цветовой палитрой во всех темах.
- На Доске статус определяется колонкой. Убран повторный выбор статуса
  внутри каждой карточки; перетаскивание и редактор задачи сохранены.
- По запросу владельца удалена «Моя неделя». Сохраненный выбор переводится
  в «Планирование»; режим «Руководство» и проверки плана остаются.
- На телефоне основные виды переключаются одной нижней панелью. Меню
  планирования и проверки доступны; верхний ряд не дублирует нижний.
- Выбранные вкладки используют палитру темы; усилен контраст невыбранного
  текста в светлой теме. Поиск мобильной шапки не занимает область добавления.
- Из шапки каталога убраны абзацы истории версий; описание и 43 карточки
  возможностей сохранены. История остается в документации и примечаниях выпуска.
- Новые возможности в справке описаны шестью короткими плитками. При открытии
  их порядок меняется, но во время чтения, изменения ширины и темы остается
  стабильным. Плитки прежних выпусков сохранены в истории версий.
- На главной странице сайта обновлены описания возможностей и начала работы.
  Разделены демо, рабочее приложение HTML, данные JSON и история браузера.
  Текстовые метки карточек растут по содержимому, не обрезая слова.
- Кнопки и фон получили мягкие статические градиенты. Палитра каждой темы,
  выбранные состояния и смысловые цвета сохранены; постоянной анимации нет.
- Невыбранные статусы больше не приглушаются общей прозрачностью.
  Счетчик Архива и подпись кнопки обучения получили более контрастный текст.
  Порядок статусов, счетчики и правила фильтрации не изменены.
- Статусы с нулем задач скрыты в полосе фильтров; «Все» остается для сброса.
  На Доске пустые столбцы скрыты по умолчанию. «Показать пустые» возвращает их,
  в том числе как места для переноса задач. Справочник статусов не меняется.
- Каталог объясняет пользу и ограничения всех 43 функций. Краткие
  характеристики собраны в плитки, техническое примечание перенесено вниз.
- Повторные подписи под девятью историческими показателями убраны.
  Общее пояснение сохранено: это не отзывы людей и не результаты нового опроса.
- В карточке автора на сайте есть «Хочу купить». Короткая форма готовит письмо
  в почтовом приложении посетителя; отправку он подтверждает сам.
  Копирование текста доступно отдельно. Данные формы не сохраняются на сайте.
- Убран нижний повторный призыв открыть демо. Верхние ссылки и каталог сохранены.

## Прогноз, легенда и зависимости

- Контрольные даты видны на первом уровне прогноза. Название, обещанная дата,
  прогноз и вывод стоят рядом на широком экране; на телефоне две даты
  остаются рядом, длинные подписи переносятся.
- Заполненность полей не выдается за надежность расчета. Критические ошибки
  данных имеют приоритет над категоричным выводом о сроках.
- Цели учитываются отдельно от контрольных точек и не удваивают их счетчик.
  Запас времени не называется задержкой; неизвестные даты обозначаются явно.
- Легенда сохраняет 14 обозначений и отдельную палитру типов работ.
- В «Связях» просмотр отделен от добавления; инструкция раскрывается отдельно.
  Название узла не сжимается рядом с ключом. Фильтр завершенных одинаково
  действует на цепочки и задачи без связей. Сортировка использует Map индексов.
- Для пустого и отфильтрованного плана сохранен заголовок таймлайна.

## Технические изменения

- `forecast-decision.mjs` содержит чистую модель итогового ответа прогноза.
  Адаптер приложения передает ей факты текущего среза. Модель не читает DOM,
  хранилище или часы; подписи, порядок причин и расчеты сохраняются.
  Сборщик встраивает модуль в автономный HTML, отдельный файл для запуска не нужен.
- Общий `status-semantics.mjs` используется валидатором данных и предпросмотром
  исправлений. Приоритет совпадает с приложением: явный `isFinal`, категория
  Jira, группа статуса, затем прежний ID `completed`.
- Предпросмотр исправлений больше не считает пользовательский финальный статус
  незавершенным и не включает `hold`/`on_hold` в замечания о сроках.
  Явный `completedStatuses`, включая пустой массив `[]`, сохраняет приоритет
  и нормализацию ID. `null` использует правила реестра, а не пустой список.
- Эти инструменты не применяют предложенные исправления автоматически.
  Формат рабочего JSON и исходные названия Jira не меняются этой правкой.
- Проверки браузера не повторяют упавший сценарий автоматически.
  Клавиатурный обход различает позиции на границе браузера и страницы.
  Контраст проверяется с учетом фактического фона, а не только цвета текста.

## Совместимость и данные

Сохраняются точное сравнение снимков, изоляция истории проектов, каскадный
порядок зависимостей, ограниченный охват отчетов, статусы Jira и встроенные
«Защищенные копии». Обновление не переносит завершенные задачи в архив
и не назначает им даты автоматически.

Перед обновлением сохраните JSON и отдельно экспортируйте точки возврата.
История браузерных версий не входит в обычный JSON. Подробный порядок есть
в `Инструкция_Roadmap.md` и `README-local.md` локального комплекта.

Рабочие данные, CSV, настройки, история, архивы, пароли и токены не включаются
в выпуск. Ранее созданные защищенные HTML остаются отдельными
снимками, без новых исправлений и без смены паролей.

Новые отчеты: `_Служебное/reports/review-2026-09-19-v16.1.0/`.
Браузерные матрицы: `source` и `built` в
`_Служебное/reports/uiux-v16.1.0/`. Они выполняются на синтетических данных
в отдельных профилях. Новые HTML и медиа требуют собственных проверок;
результаты v16.0.1 не переносятся в итог v16.1.0.

В GitHub Release разрешены только `Roadmap-v16.1.0-public.zip` и
`Roadmap-v16.1.0-public.zip.sha256`. Локальный и полный ZIP остаются локально.
Старые теги и вложения не заменяются новым выпуском. GitHub Actions, сайт
и скачиваемый публичный архив проверяются отдельно после размещения.
Созданный локально ZIP не является подтверждением публикации.

Новый тег v16.1.0 указывает на итоговый проверенный commit. Отправка тега
запускает verify/package, но не загрузку отдельного site ZIP в релиз.
Ручной режим `publish_release=true` для этого выпуска не используется.
GitHub Release создается отдельно с ровно двумя разрешенными вложениями.
