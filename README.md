# Roadmap

**Профессиональный план продукта в одном автономном HTML-файле.**  
Задачи и статусы, интерактивный Гант, критический путь, выравнивание команды, прогноз сроков и представительские материалы для руководства. Работает локально в любом современном браузере без установки сервера, Node.js или базы данных.

---

**v16.5.0 от 20.09.2026** — стабильный релиз:
- 🚀 **Экспорт отчета по резервам времени в PDF**: наглядная сводка запаса хода задач (Float / Slack) для оценки рисков срыва дедлайна.
- 🎯 **Канонический расчет CPM (Critical Path Method)**: математически выверенный поиск критической цепочки и расчет запаса времени для сложных графов зависимостей.
- 🔍 **Режим «Только критический путь»**: мгновенная фокусировка таймлайна на задачах, непосредственно влияющих на дату запуска.
- 👥 **Интеллектуальное выравнивание ресурсов (Resource Leveling)**: автобалансировка перегрузок команды с каскадным сдвигом связанных задач.

## ⚡ Быстрый старт

### 1. Попробовать прямо сейчас
Откройте [онлайн-демо](https://uchvru.github.io/roadmap/app.html) в браузере. Интерактивная песочница с демонстрационным проектом позволяет протестировать таймлайн, доску, выравнивание команды и генерацию отчетов без предварительной настройки.

### 2. Работать со своим проектом
1. Получите у владельца проекта рабочий файл `Roadmap-v16.5.0-local.zip` (или полный комплект `Roadmap-v16.5.0.zip`).
2. Распакуйте архив в любую удобную папку на компьютере.
3. Откройте файл `roadmap.html` в браузере (Chrome, Safari, Edge, Firefox).
4. Выберите «Создать пустой план», импортируйте задачи из Jira/CSV или начните с шаблона «Первый рабочий план».
5. Сохраняйте файл плана в JSON одним кликом — все данные хранятся исключительно на вашем устройстве.

> **100% приватность:** Ваши данные никогда не отправляются в облако. Все расчеты, построение графиков и экспорт отчетов выполняются на стороне клиента.

## 💎 Ключевые возможности

### 📊 Планирование и управление сроками
- **Единый источник правды:** мгновенное переключение между Сводкой, Диаграммой Ганта, Канбан-доской, Матрицей инициатив и экраном прогноза «Успеваем?».
- **Критический путь и резервы времени (CPM):** расчет критических цепочек и количества дней свободного запаса (Slack) по каждой задаче.
- **Поддержка любых типов связей:** Finish-to-Start (FS), Start-to-Start (SS), Finish-to-Finish (FF), Start-to-Finish (SF) с учетом задержек (Lag).
- **Иерархия Jira:** сквозная структуризация «Инициатива → Эпик → Задача/История → Подзадача» с сохранением исходных статусов.

### 👥 Команда и балансировка нагрузки
- **Тепловая карта загрузки:** визуальный контроль перегрузок (>100%) и резервов мощности (<60%) специалистов.
- **Умное выравнивание очереди (Resource Leveling):** автоматическое устранение конфликтов дат у исполнителя с каскадной синхронизацией зависимостей.
- **Производственный календарь:** учет праздников, выходных, индивидуальных отпусков и ставок специалистов (CAPEX/OPEX).

### 👔 Представительские отчеты для руководства
- **Минута на статус (One-Pager):** готовая одностраничная выжимка ключевых вех и рисков для синхронизации со стейкхолдерами.
- **Отчет по резервам времени (PDF):** структурированная аналитика критических задач и запаса времени до срыва дедлайна.
- **Генератор слайдов (Deck):** автоматическое создание презентации проекта в альбомной ориентации для совета директоров.

## 🛠 Содержимое репозитория

Публичный репозиторий [uchvru/roadmap](https://github.com/uchvru/roadmap) обеспечивает работу сайта и демонстрационной версии через GitHub Pages:

- `index.html` — промо-страница проекта и видеодемонстрация.
- `app.html` — интерактивное веб-приложение на синтетических данных.
- `catalog.html` — иллюстрированный каталог 43 функциональных возможностей.
- `Инструкция_Roadmap.md` — подробное руководство пользователя и архитектурное описание.
- `media/`, `catalog-img/` — медиа-ресурсы и версионные манифесты целостности.
- `.quality/` — скрипты проверки качества сборки (`verify-public.mjs`, `bump-version.py`).
