Заблокировать паролем

Все происходит в вашем браузере, файлы и пароль никуда не отправляются.

Будут созданы и заменены сразу четыре файла: roadmap-mpv0.html, roadmap-online.html, roadmap-online-r.html и roadmap-online-n.html. Для первого нужен HTML из кнопки «Сохранить в HTML»; для остальных — приложение и JSON. Рядом появится roadmap-package-manifest.json с контрольными SHA-256 всего готового набора.

Пароли не сохраняются. Для каждого файла нужен свой пароль: не короче 14 символов. Надёжнее использовать фразу из четырёх или более слов.

roadmap-mpv0.htmlПоказ из «Сохранить в HTML»
roadmap-online.htmlОсновная ссылка, только просмотр
roadmap-online-r.htmlРедактируемая версия
roadmap-online-n.htmlВерсия без редактирования
Как обновить: выберите существующий файл в папке roadmap/private и подтвердите замену. Так новая версия точно сохранится под прежним именем, без копий «(1)». После загрузки на GitHub откройте ссылку с новым параметром ?v=..., который появится в сообщении ниже: GitHub Pages может держать старую копию до 10 минут. Пароль передавайте отдельно. Режим правки: изменения сохраняются в браузере того, кто правит; для общей ссылки выгрузите свежий JSON и пересоберите файл.
